# TomTroc

The goal of this project is to create a website that connects readers so they can share and exchange books (training)

## Pour utiliser ce projet :

- Commencer par cloner le projet.
- Une fois installé chez vous, créez un base de données vide appelée : "tom_troc"
- Importez le fichier tom_troc.sql dans votre base de données.

## Lancez le projet !

Pour la configuration du projet créer un fichier db_config.php et éditez le avec les informations nécessaire à la base de données.

Pour vous connecter créer un utilisateur.

## Problèmes courants :

Limite de taille des fichier uploader (ex: photo ustilisateur).
Lancer le serveur web intégré de PHP en local sur http://localhost:8080, en forçant l’utilisation du fichier de configuration php.ini de XAMPP.
